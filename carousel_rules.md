# CAROUSEL RULES - SCRIPT FRAMEWORK

Version: 2.0.0

Purpose:
Generate educational and informational carousels using the SCRIPT framework while utilizing pose assets as supporting visual elements.

---

# PRIMARY FRAMEWORK

Every carousel should follow:

S → C → R → I → P → T

The framework determines:

* content flow
* slide objective
* emotional progression
* pose selection

---

# S — SCROLL STOPPER

Objective:

Stop the user from scrolling.

Create curiosity.

Generate emotional interruption.

---

Recommended Content:

* Surprising fact
* Bold statement
* Common mistake
* Pain point
* Question

---

Recommended Poses:

Wondering
Curious
Shock
Thinking
Yelling

---

Pose Usage:

Optional

Recommended Crop:

Close Up
Medium Close Up

Recommended Position:

Bottom Right
Bottom Left

---

# POSE DENSITY RULE

Do not place poses on every slide.

Recommended:

30% - 50% of total slides.

Example:

8 slides:
3–4 slides use poses.

10 slides:
4–5 slides use poses.

---

# TEXT PRIORITY RULE

Text always has priority over pose assets.

If overlap occurs:

1. Resize pose.
2. Reposition pose.
3. Crop pose.
4. Remove pose.

---

# SAFE AREA RULE

Text Area:

70% minimum

Pose Area:

30% maximum

---

# FLIP RULE

Allowed:

Horizontal Flip

Purpose:

Character should face the content.

Character should point toward content.

Character should direct visual attention.

---

# NO POSE RULE

Do not use pose assets on slides containing:

* Charts
* Statistics
* Tables
* Infographics
* Timelines
* Process diagrams
* Dense information

---

# FINAL RULE

The carousel must remain completely understandable even if every pose asset is removed.

Pose assets enhance communication.

Content delivers communication.
